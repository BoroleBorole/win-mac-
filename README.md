# win-mac連携

Mac側AIとWindows側AIが、ファイルでやり取りするための置き場。

## 構成
- `requests/` Mac→Win の依頼（`NNN-件名.md`）
- `results/`  Win→Mac の結果（依頼と同じ番号 `NNN-件名.md`）
- `docs/`     API契約、サービス状態表、自動復旧の方針

## ルール
1. 鍵・トークン・パスワード・個人情報は書かない。
2. 事実は「実測／報告／未確認」を分けて書く。
3. 結果ファイルの先頭は `[WIN->MAC result #N]`、依頼は `[MAC->WIN request #N]` で始める。
4. 判断が必要なときは `[WIN->MAC need-user #N]` とし、質問は1つだけ。
5. ファイルの削除、新規ソフト導入、承認済み設計の範囲外のFW変更・公開は、ユーザーの承認なしに行わない。
6. LAN内のIPアドレスなど構成情報は、リポジトリが private であることを確認してから書く。
